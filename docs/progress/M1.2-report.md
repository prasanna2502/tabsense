# M1.2 Report — Expanded-view readability + manual cleanup for similar documents

Date: 2026-10-08 · Milestone: M1.2 · Status: build complete and verified; final sign-off is the user's in-Chrome review of the expanded views

## 1. Shipped
- **Nested disclosure for Similar documents.** Each fuzzy set is now its own
  collapsed card (same look as the exact-duplicate cards). Opening the section
  shows only compact group headers — favicon, one-line title, host, "N views" —
  and no member rows until that specific group is expanded. Open state survives
  snapshot re-renders. The section note is one line: "Same document in different
  views. TabSense won't close these unless you choose to."
- **Compact member rows.** Duplicate and similar cards no longer repeat the
  document title plus an opaque `…/document/d/<id>` path on every row. Each
  member is a short **view descriptor** derived from structural URL signals
  only — Sheets tab gid ("Sheet tab 3"), Docs mode ("Edit view", "Read view",
  "Preview", "Comment view") with "· linked section" / "· linked position"
  fragment suffixes, Slides "Linked slide", Figma "Selected element" /
  "Page view", YouTube "Starts at 1:30" / "Playlist view" / "Shorts view",
  GitHub "Code line link", and within-group generic fallbacks ("Linked
  section", "Different page options", "Different page view", "Another view").
  Repeated descriptors within a group get ordinal suffixes so every row reads
  differently. Descriptors never contain a document ID or a raw query value.
  Alongside the descriptor: "Last used {time}" (from `chrome.tabs`
  lastAccessed, "Opened {time}" fallback) and a Current pill. Exact-duplicate
  members use positional descriptors ("Newest copy", "Copy 2", …).
- **Manual cleanup for similar documents.** Inside each expanded group: a hint
  line, one radio per view (choose the view to keep), and a **Close other
  {N} views** button. Default keep: the active tab if it is a member, else the
  most recently accessed view; a changed selection survives re-renders while
  the tab remains a member. Row clicks select the radio; a small **Open**
  button is the navigation affordance. The worker re-derives the live fuzzy
  set at click time (`planSimilarClose`), requires the keep tab to be a
  current member, re-validates every tab (tracked, not excluded, still
  carrying the fuzzyKey) before closing, and logs one `bulk-close` activity
  entry per closed view — so closed views appear in Recently closed with
  Reopen. Fuzzy matches remain **never auto-closed**; this is explicit,
  per-group, and user-initiated only.
- **All tabs progressive disclosure.** With no search query, the section
  renders at most 40 rows plus a "Show all {N} tabs" button (state survives
  re-renders). Search always shows all matches.
- **Needs attention copy fix.** With zero exact extras but similar documents
  present, the card now says "No exact duplicates" and points at the optional
  review below. "Everything is tidy" is reserved for zero exact extras **and**
  zero fuzzy sets.
- `TabInfo` now carries `lastAccessed` (existing `tabs` permission). The
  toolbar badge and Needs attention counts stay exact-tier only.

## 3. Decisions
- **Descriptors describe the view, never the document.** The title already
  names the document once, in the card header; member rows differentiate by
  state (sheet tab, mode, anchor, start time) and recency — the two things a
  user actually chooses between. Document IDs and raw query values are noise
  and stay out; the only values ever shown are a sheet gid and a video start
  time, which are precisely that state.
- **Radio + Open button, not row-click navigation, inside similar groups.**
  A stray navigation click mid-cleanup would lose the user's place in the
  group; selecting is the safe default gesture there, and Open remains one
  click away. Exact-duplicate member rows keep click-to-activate, since
  there is no selection in play.
- **The keep default is recomputed until touched.** An untouched group's
  default tracks the active/most-recent view across re-renders; once the
  user picks a radio, that choice is authoritative while the tab remains a
  member. Stale choices for vanished groups are pruned on render.
- **Same revalidation discipline as close-all.** The similar cleanup plans
  from the worker's live index and re-checks membership immediately before
  each close, so a stale panel can never close a tab that has navigated
  away from the set.
